# Atividade de Fixação 06 - Gráficos 📊

Repositório com os scripts em Python para geração de gráficos da Atividade 06.

## 🛠️ Tecnologias
* Python
* Pandas, Matplotlib e Seaborn

## 📂 Arquivos
Cada arquivo `.py` na raiz gera o seu respectivo gráfico a partir dos dados CSV:
* `01_grafico_barras.py`
* `02_grafico_boxplot.py`
* `03_grafico_dispersao.py`
* `04_grafico_distribuicao.py`
* `05_grafico_frequencia.py`
* `06_grafico_heatmap.py`
* `07_grafico_linhas.py`
* `08_grafico_pizza.py`
* `09_grafico_regressao.py`

## 🚀 Como Executar

1. Instale as dependências:
   ```bash
   pip install pandas matplotlib seaborn

   2. Execute o script desejado:
   ```bash
   python 01_grafico_barras.py
